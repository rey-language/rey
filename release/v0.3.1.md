# Rey v0.3.1 — Release readiness

**Version:** v0.3.1
**Build preflight:** all five release targets passed in [workflow run 39476719115](https://github.com/rey-language/rey/actions/runs/39476719115)
**Publication:** tag-triggered workflow publishes the release after repeating the target builds.

## Patch contents

- Vec capacity growth uses `realloc` instead of allocating and zeroing a second full buffer. Only live kind metadata is initialized. The current macOS arm64 comparison measured 36–48% lower peak RSS on large Vec workloads.
- Restored the missing native typechecker and checked-program backend as a matching source pair. The tracked driver already required their APIs, but the repository contained an old checker stub and backend. Recovery provenance and limits are recorded in [BOOTSTRAP-SOURCE-RECOVERY.md](../docs/BOOTSTRAP-SOURCE-RECOVERY.md).
- The release builder compiles the tracked Rust reference interpreter, runs the current compiler source through it to build stage 1, then uses stage 1 to rebuild the packaged native compiler. The package must report exactly `rey 0.3.1`. The Rust bootstrap is not distributed.
- Every target rebuilds the runtime from tracked C sources using matching platform tools. Windows selects the Win32 file, directory, and process implementation in `runtime/io_windows.c`; Unix uses `runtime/io.c`. This avoids the LLVM bitcode compatibility problem in v0.3.0 archives. All packages bundle current `std/src`.
- Native compiler triples are Apple Darwin, Linux GNU, and Windows GNU. Linux release packages link through the existing Zig musl wrappers. The compiler detects its native host triple; there is no cross-target CLI option in v0.3.1.

## Validation and limits

The five-target hosted package-build preflight passed on macOS arm64, macOS x86-64, Linux x86-64, Linux aarch64, and Windows x86-64. The tag workflow repeats those builds and requires all five assets before publication. This release build does not run the complete runtime or language conformance suites; build success does not establish conformance or new performance results.
