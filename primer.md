## What I know so far
Rey is an experimental dynamically-typed language with optional type annotations. The v0 reference interpreter is a Rust implementation with a lexer, recursive descent parser, and tree-walk interpreter. Core features include variables, functions, control flow, and built-in types (int, string, bool, null). The language prioritizes simplicity and explicit design over cleverness.
