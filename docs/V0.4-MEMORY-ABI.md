# v0.4 native memory contract, revision 1

This is the contract for new native code and the Rey runtime. The trusted fixed-layout heap and explicit-root collector implement the initial subset in [V0.4-FIXED-HEAP-CONTRACT.md](V0.4-FIXED-HEAP-CONTRACT.md); compiler-generated managed references and roots remain pending. This ABI is not binary-compatible with the historical C runtime. The coordinator owns revisions; backend/runtime workers consume the same revision.

## References and object layout

- A managed reference is either null or the allocation's canonical base address. It is never an arbitrary integer or an interior byte pointer.
- Native objects are 16-byte aligned. The 16-byte header contains `layoutId: u32` at offset 0, runtime flags at offset 4, and payload byte length as `u64` at offset 8. These widths are internal representation requirements, not newly approved public user types. Flags include collector mark state; ordinary user code cannot modify them.
- A layout ID identifies an immutable tracing/layout descriptor, not source nominal identity. Nominal identity remains a separate checker/IR property. All allocation and offset/size arithmetic is checked.
- Payload fields begin at offset 16. Descriptors define size/alignment, reference offsets, tagged-variant scans, and variable-length element scans. Code pointers and raw owned buffers are not managed references.
- String payload starts with its byte length, followed by exactly that many bytes and a trailing zero. Embedded zeros remain data. A string value references the canonical object; raw byte access derives a temporary address at base + 24. C-string conversion is an explicit OS/foreign bridge operation.
- A derived pointer records its owner and offset in IR. It cannot be the only surviving reference across collection. Retain the owner root, then reconstruct the address. Borrowed views arrive only after their lifetime is established.

## Containers and buffers

- A Vec carries length, capacity, its exclusively owned raw-buffer address, and an element layout descriptor. The descriptor supplies element stride and tracing behavior even for the untagged fast path. `Vec<int>` and `Vec<string>` cannot share an unspecified scan policy.
- Trace initialized elements in `[0, len)`. Do not scan unused capacity or interpret pointer-shaped integer/float bits as references. Tagged `any` slots require a real discriminant and the corresponding scan rule.
- A map owns its entry buffer. Trace live keys and reference-bearing values only; ignore empty/tombstone entries. Rehash transfers raw-buffer ownership and releases the previous buffer exactly once.
- Raw-buffer allocation/release is a separate internal API from managed object allocation. Reclaim a dead container's owned buffer once during sweep. A buffer address cannot be held across resize without an established stable-owner protocol.
- Closure descriptors distinguish executable pointers from environment references. Tuple, enum, Option, Result, nullable, and boxed values have exact descriptors rather than conservative word scanning.
- The old string-pointer membership table is not carried over as a permanent strong root. Any replacement index must remove stale addresses and must not keep every historical string alive.

## Roots, allocation, and safepoints

- Bring up a non-moving, stop-the-world tracing collector with a single mutator first. No finalizers, weak references, moving nursery, or reference counting in this initial collector.
- Every call has an explicit `mayCollect` property. Before such a call or an explicit poll, publish all live references in initialized typed shadow-stack slots. Registers/spills cannot hold the only unregistered copy.
- Root sources include globals, compiler-generated frames, runtime construction temporaries, task handles/queues, and region-to-heap references. Interior references retain their canonical owner.
- Allocation can collect before it returns a new object. A new object's traced fields are zero before a scan can see it. Root partially built objects and intermediate operands before another collecting operation. Zeroing elimination is a later verified transformation.
- Stack/region objects are registered with their storage class and descriptor so their heap-reference fields are traced without treating them as individually sweepable heap allocations.
- Collector work storage cannot recursively trigger collection. Use an explicit worklist and defined OOM handling; do not recurse through arbitrary user graph depth.
- Recycle empty blocks and apply a documented trimming policy. Report live, reserved, and resident bytes separately. Keeping blocks reserved is not proof of a leak or proof that memory was returned to the OS.

## Regions and promotion

- Region create/allocate/reset/end are explicit IR operations. Reset requires established absence of surviving references from managed objects, callers, globals, closures, tasks, and other longer-lived storage.
- A region may hold references to heap objects; those references are roots until the region ends. A longer-lived object cannot retain a reference into a region that will reset.
- Initial promotion chooses a sufficiently long-lived destination before allocation. Returned aggregates can receive a hidden destination and layout/lifetime contract. Unknown escapes allocate on the managed heap.
- General runtime relocation is not silently implemented as a copy: it requires a separate protocol covering every alias, cycle, and boundary reference. Until that gate exists, preserve identity using safe storage selection.
- Long-running loops need iteration/phase lifetimes, not an arena retained until the whole function returns. Do not retain an entire request arena to preserve one small result without reporting that retention.

## Structured tasks

- v0.4 includes `spawn`, consumed-once `Task<T>.join()`, and isolated `parallel for` after the single-mutator collector passes. Tasks are joined on all exits; there are no detached tasks in this surface.
- Spawn arguments/results are scalars, strings, and recursively value-only tuples/enums/Option/Result. Structs, Vecs, maps, closures, `any`, and task handles cannot be transferred as ordinary task payloads. The initial implementation copies value payloads into task-owned storage; output roots transfer before task teardown.
- Task bodies have no I/O/process effects, mutable-global access, or shared aggregate mutation. Enforce isolation transitively, with unknown calls rejected. Join helps execute work rather than blocking every worker on a saturated pool.
- Parallel loops permit disjoint writes at their iterator index in scalar vectors. Writable outputs must not alias read inputs or each other: prove it statically or perform an explicit disjoint-buffer check before scheduling. Inputs remain read-only until completion; no resize/struct mutation or nested parallelism in the first surface.
- Task errors are retained as task outcomes and surface at join. Parallel-loop errors report the smallest failing iteration in source order. Do not print schedule-dependent worker errors immediately.
- Create the fixed worker pool lazily at first parallel use. Publication/transfer uses specified release/acquire synchronization; deque algorithms must use their separately verified ordering rules. Numeric writes and thread-local allocation do not automatically become atomic.
- Extend stop-the-world coordination to every mutator, including idle/joining workers. Roots must be published before parking. Task queues and completed-but-unjoined results retain roots. Define cancellation/worker-exit teardown before adding cancellation APIs.

## Required evidence

Force collection at every allowed safepoint in correctness mode. Exercise references across calls/branches/loops/spills, strings with embedded zeros, pointer-shaped integers, raw fast-path vectors, nested containers, closures, cycles/deep graphs, partial construction, growth/deletion, region escapes, and task handoff/joins. Compare optimized/unoptimized behavior and record allocation/copy counts, live/reserved bytes, RSS, retained-region bytes, and collection pauses separately from headline uninstrumented timing.
