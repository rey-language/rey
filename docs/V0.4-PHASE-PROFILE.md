# v0.4 compiler IR retention profile

P01 measures the region compiler's runtime reload, lowering, verification and
link-copy phases. The profile is opt-in through
`REY_COMPILER_RETENTION_PROFILE=1`; regular compiler builds do not print phase
events. Its event lines use the `REY_RETENTION` prefix and are kept separate
from compiler diagnostics by the acceptance harness.

The copy counters report **logical nested IR payload bytes** reconstructed by
`copyFunction`: function signature type entries, parameter and block values,
basic-block records, instruction records, operand entries, terminator argument
entries, and effect escape entries. They exclude the allocator's headers and
capacity slack, shared string data, and the top-level `IRFunction` records in
the combined function vector. The control total models the prior implementation
that deep-copied user and runtime functions; the retained total counts the
runtime copies still required to shift function IDs. This metric is a
structural copy measure, not a claim about allocator bytes.

The harness also records wall-time boundaries between phase events and whole
compile peak RSS from `/usr/bin/time -v`. Timed profile runs include the cost of
walking IR to report shapes and copy estimates. The peak-RSS gate uses three
clean, non-profiled runs per control/current fixture. Profile timing is
diagnostic only.

## Why unchanged user IR is shared

`IRProgram` and the IR records are constructed as frozen values; consumers
read their nested vectors unless they first construct a replacement program.
The relevant consumers were audited:

- `linkRegionRuntime` reads user function IDs and contents for validation,
  runtime binding discovery, and placement data. It does not rewrite user IR.
- `verifyProgram` uses local function indexes and verifier workspace.
- `planManagedPlacement` builds local graphs, indexes, and placement vectors;
  it reads `module.program` without writing into its functions.
- `applyScalarReplacementForCompilerFast` returns a new managed module and
  rebuilt IR program. The completed region lowering receives that replacement.
- Both region lowering paths construct new program/function vectors before
  replacing transformed functions. `lowerManagedRegionsWithPromotionStress`
  deep-copies the linked program first; completed lowering builds a new vector
  and leaves untransformed function values unchanged.
- The final verifier and native emitter only read the resulting IR.

The runtime functions are still deep-copied because their call targets receive
the user-program ID shift. User functions keep their original IDs and are
inserted unchanged. P01 does not change placement policy or verification
cutoffs.

The harness pins the pre-P01 linker control at SHA-256
`af3b2dc9614d1954f9ff62433e14a2086830aead2ac25ab2878938768c495975`. It builds
control and current staged IR pipeline drivers with the supplied seed. Each
driver checks the fixture source, performs completed region lowering, verifies
the result, and writes its final IR dump to stdout. The harness compares those
result dumps and compiler diagnostics for the small case, 511/512/513 function
boundaries, and a scaled 2049-function input. It runs each driver three times
per case for peak-RSS measurement. It then invokes the R01 region gate with the
seed and current source tree; R01 builds its own staged drivers from the current
modules.

## Reproduction

```sh
sh tests/v04/compiler-retention/run.sh \
  /home/ubuntu/rey/wt/P01 \
  /home/ubuntu/rey/discovery/selfhost/S3 \
  /home/ubuntu/rey/wt/P01 \
  /home/ubuntu/rey/wt/P01-accept \
  --staged --repeats 3
```

The runner wraps every Rey build with `scripts/v04-linux-x64-budget.sh`, then
checks and enters a nested systemd cgroup scope using the wrapper's computed
memory cap and a 512 MiB swap cap. It fails closed if neither the user scope
nor the passwordless system scope enforces the requested values. The scope also
sets nice 19 and a bounded timeout. All drivers, outputs, logs, timing files,
and reports stay in the external output directory. Retries after an existing
attempt use a new child directory and preserve the earlier attempt. Acceptance
requires matching lowered-IR results and diagnostics, at least a 10% scaled reduction in
logical link-copy bytes, no scaled peak-RSS regression greater than 5%, and a
passing staged R01 region gate.
